Mitbauen mit AIS.chat

AIS.chat liefert den fertigen Code als Text, aber keine Vorschau und keine Datei. Deshalb: links bauen lassen, rechts in der HTML-Vorschau ansehen und speichern. · Zur Startseite

Anleitung: Vibe Coding mit AIS.chat

  1. Chat starten

    AIS.chat öffnen und links auf Neuer Chat klicken.

  2. Auftrag geben

    Klicken Sie unten ins Eingabefeld und fügen den Prompt als Text ein. Den Prompt erstellen Sie im Prompt-Baukasten (Formular) oder im Prompt-Baukasten frei mit „Prompt kopieren“.
    Oder: dort „Als .md speichern“ klicken, die Datei über die Büroklammer im Eingabefeld anhängen und schreiben:

    Baue das Programm aus der angehängten Datei. Gib den kompletten Code als eine einzige HTML-Datei in einem Codeblock aus.

  1. Code kopieren

    Die Antwort enthält einen Codeblock html – vokabeltrainer.html. Klicken Sie rechts oben im Block auf das Kopier-Symbol. Beantworten Sie vorher Rückfragen der KI kurz und prüfen Sie den Plan.

  1. Rechts einfügen und speichern

    Auf der Seite rechts in das Feld „Hier HTML-Code einfügen“ klicken, mit Strg+V einfügen (Tablet: lange tippen, Einsetzen). Die Vorschau zeigt sofort das Ergebnis. Prüfen Sie es, tragen Sie einen Dateinamen ein und klicken Sie auf Speichern. Die Datei starten Sie später per Doppelklick im Browser.

Fehler gefunden? Melden Sie im Chat einen Fehler pro Nachricht: „Ich habe … geklickt. Passiert ist … Erwartet hatte ich …“. Den neuen Code wieder kopieren und rechts einfügen.
Sicher nutzen
  • Nur Beispieldaten, keine Schülerdaten, in AIS.chat und in die Apps.
  • AIS.chat kann Fehler machen. Prüfen Sie Inhalte, Bedienung und Barrierefreiheit, bevor die App in die Klasse geht.
  • Stecken Daten oder eine Anmeldung in der App, ist sie nicht für Lernende geeignet, bis Sie das geprüft haben.

HTML-Vorschau

Die Vorschau läuft abgeschottet und lädt nichts nach. Das Speichern des Lernstands (Lernstand bleibt nach dem Neuladen) funktioniert hier nicht, testen Sie es in der gespeicherten Datei per Doppelklick. Es wird nichts hochgeladen, alles bleibt auf Ihrem Gerät.
